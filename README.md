# WxADT — 微信极客插件

基于 **LSPosed** 框架的微信增强模块，适配微信 **8.0.72**。

> ⚠️ 本项目仅供学习与技术研究使用，请遵守相关法律法规及微信用户协议，**禁止用于任何商业或非法用途**。

---

## 功能列表

| 功能 | 说明 |
|------|------|
| 🤖 AI 智能回复 | 接收消息后自动调用 AI 大模型生成回复，支持所有 OpenAI 协议兼容接口 |
| 🛡️ 防撤回 | 阻止好友/群成员撤回消息，撤回内容在聊天框中永久保留 |
| 🎵 语音变声 | 发送语音前自动调用外部服务完成 AI 变声，变声失败时取消发送 |
| 💰 自动收款 | 收到转账时自动打开收款页并确认收款，支持自定义延迟 |
| 🧧 自动收红包 | 收到红包时自动打开并领取，领取后自动关闭结果页，支持自定义延迟 |

---

## 环境要求

- **Android**：8.0（API 26）及以上
- **Root 框架**：Magisk 或 KernelSU
- **LSPosed**：[LSPosed](https://github.com/LSPosed/LSPosed) 已安装并启用
- **微信**：8.0.72（其他版本未测试，可能不兼容）

---

## 安装步骤

### 1. 安装 LSPosed

1. 确保手机已 Root（Magisk ≥ 24 或 KernelSU）
2. 在 Magisk / KernelSU 中刷入 LSPosed 模块
3. 重启手机，打开 LSPosed 管理器确认框架已激活

### 2. 安装本模块

1. 从 [Releases](../../releases) 页面下载最新的 `WxADT-*.apk`
2. 安装 APK（允许安装未知来源应用）
3. 打开 **LSPosed 管理器** → 模块 → 找到 `WxADT`
4. 勾选 **启用**，并在作用域中勾选 **微信（com.tencent.mm）**
5. **强制停止微信**并重新启动，使模块生效

### 3. 验证安装

打开 WxADT 应用，若界面显示 **"模块已激活 ✓"**（绿色），则安装成功。

## 使用方法

### 打开控制面板

1. 打开微信，进入任意**设置页面**（微信 → 我 → 设置）
2. 屏幕右下角会出现悬浮按钮 **🛡️ 极客面板**
3. 点击该按钮打开控制面板，配置各项功能后点击 **保存**

> 配置立即生效，无需重启微信。

## 功能详细说明

### 🤖 AI 智能回复

开启后，收到新消息时自动在 5 秒内批量收集，调用 AI 接口生成回复。

**配置项：**

| 配置 | 默认值 | 说明 |
|------|--------|------|
| 接口地址 | 阿里云百炼（千问） | 支持任何 OpenAI 兼容接口，如 DeepSeek、本地 Ollama 等 |
| 模型名称 | `qwen3.6-plus` | 填写对应平台的模型 ID |
| API Key | 内置测试 Key | 建议填写自己申请的 Key，防止限流 |
| 批量等待 | 5000 ms | 收到第一条消息后等待多久一起处理（避免频繁调用） |
| 携带消息条数 | 20 条 | 发给 AI 的历史上下文轮次数量 |
| 系统提示词 | 内置默认 | 点击编辑按钮可自定义 AI 的角色人设和回复风格 |

**支持的 AI 服务（示例）：**

```
# 阿里云百炼（默认）
接口地址：https://dashscope.aliyuncs.com/compatible-mode/v1
模型：qwen-max / qwen-plus / qwen-turbo

# DeepSeek
接口地址：https://api.deepseek.com/v1
模型：deepseek-chat / deepseek-reasoner

# OpenAI
接口地址：https://api.openai.com/v1
模型：gpt-4o / gpt-4o-mini

# 本地 Ollama
接口地址：http://192.168.x.x:11434/v1
模型：llama3 / qwen2.5 等（无需 Key）
```

**特殊指令：**
- 在任意聊天中发送 `重置对话` 可清除该联系人的上下文历史

---

### 🛡️ 防撤回

开启后，当对方撤回消息时，原消息内容仍会在聊天界面保留显示，不会消失。

无需额外配置，开关即用。

---

### 🎵 语音变声

发送语音前，将音频通过外部 HTTP 接口进行 AI 变声，再发送变声后的音频。若变声请求失败，则**取消本次发送**，不会发出原声。

**需要自行搭建变声服务器。**

**配置项：**

| 配置 | 默认值 | 说明 |
|------|--------|------|
| 服务器地址 | `http://192.168.x.x:8000/convert` | 变声 API 的完整 URL |
| 音色名称 | `speaker1` | 目标音色，由服务端定义 |

> 服务端接口规范：接受 POST 请求，Body 为原始 AMR 音频，返回变声后的 AMR 音频。

---

### 💰 自动收款

开启后，收到微信转账时自动确认收款，无需手动点击。

**配置项：**

| 配置 | 默认值 | 说明 |
|------|--------|------|
| 延迟 | 1000 ms | 收到转账消息后等待多少毫秒再确认，防止过于明显 |

---

### 🧧 自动收红包

开启后，收到红包消息时自动打开并领取，领取完成后自动关闭结果页。

**配置项：**

| 配置 | 默认值 | 说明 |
|------|--------|------|
| 延迟 | 1000 ms | 收到红包消息后等待多少毫秒再开抢，留空则使用默认值 |

## 从源码构建

```bash
# 克隆仓库
git clone https://github.com/<your-username>/WxADT.git
cd WxADT

# 用 Android Studio 打开，或直接命令行构建
./gradlew assembleDebug

# APK 输出路径
app/build/outputs/apk/debug/app-debug.apk
```

**构建依赖：**
- Android Studio Hedgehog 或更新版本
- Android SDK 34+
- JDK 17+
- LSPosed API（已通过 Gradle 依赖自动引入）

**（可选）配置私人默认值：**

debug 构建支持通过 `local.properties` 预置默认 API Key 和变声服务器地址，方便本地开发调试：

```properties
# 在项目根目录的 local.properties 中添加（此文件不会上传 GitHub）
default_ai_key=sk-xxxxxxxxxxxxxxxx
default_voice_url=http://192.168.x.x:8000/convert
```

release 构建不内置任何私人信息，这些字段会为空，用户通过面板自行填写。

## 常见问题

**Q：模块安装后显示"未激活"？**
> 检查 LSPosed 作用域是否勾选了微信，然后强制停止微信重启。

**Q：极客面板悬浮按钮不出现？**
> 确认进入的是微信**设置页**（不是聊天页），如果仍不出现，请重启微信再试。

**Q：AI 自动回复没有反应？**
> 检查 API Key 是否正确，可查看 LSPosed 日志（标签 `WxADT`）确认错误原因。

**Q：自动收红包提示成功但没领到？**
> 红包可能已被抢完或已过期，这属于正常情况。

**Q：语音变声发送失败？**
> 确认变声服务器可正常访问（手机与服务器在同一网络），检查服务器地址配置。
